# 播客工坊

先经稳定CLI/MCP发现当前作品、活动包、Schema及同包方法，携带精确WorkRef、management_ref和活动摘要。先读已有工程、来源和意见，不要求作者重复填写对话内容。

固定节目目标和台本 → 接入真实录音与准确选段 → 章节和独立出场 → 核对实际时长 → 试听并按固定意见返工 → 复核旧编排 → WAV、章节JSON和完整工程。

录音与原始选段只追加，逐字转录固定文字来源，入出点依据真实PCM16 WAV帧。转录是提交者声明，合成测试音不冒充真人说话。章节台本与声音分别保存，改台本后旧编排与意见过期。编排固定章节、选段和录音组合摘要；已过期编排不能渲染，明确复核后才重新固定。按单通道顺序拼接选段与真实静音，不默重采样、不修改音高或压缩时长，输入必须同采样率／声道。章节时间从实际输出帧推导，重复章节允许但有独立出场；不从文字猜语音时间。

[工作流程](references/workflows.md)解释专业取舍、媒体和接续；[操作地图](references/operations.md)由清单生成。每次保存回读固定修订，未知先get_operation，CAS保留原输入。create_handoff记录阶段依据和下一步。素材可读取不代表获准外发；费用、采纳、定稿及发布按作者确切决定。
