# Skill与机器接续

包内hetu-podcast-studio由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：固定节目目标和台本 → 接入真实录音与准确选段 → 章节和独立出场 → 核对实际时长 → 试听并按固定意见返工 → 复核旧编排 → WAV、章节JSON和完整工程。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

录音与原始选段只追加，逐字转录固定文字来源，入出点依据真实PCM16 WAV帧。转录是提交者声明，合成测试音不冒充真人说话。章节台本与声音分别保存，改台本后旧编排与意见过期。编排固定章节、选段和录音组合摘要；已过期编排不能渲染，明确复核后才重新固定。按单轨顺序拼接选段与真实静音，不默重采样、不修改音高或压缩时长，输入必须同采样率／声道。章节时间从实际输出帧推导，重复章节允许但有独立出场；不从文字猜语音时间。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
