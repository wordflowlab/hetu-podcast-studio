# 产品需求

## 背景与推导

播客的台本与录音有不同生命周期。改过串词不代表录音已更新，转录文字也不证明实际声音。工程需要保存录音原件、准确选段和独立出场，才能在每次结构调整后知道哪些声音还适用。Agent操作完整计划，作者阅读、试听和反馈，软件重复执行固定剪接与交付。

生成成本和等待时间会变化，但固定作品、历史依据、具体意见与连续审阅仍需长期积累。固定工程避免让模型每轮重建结构；结构化数据与多种阅读方式共用同一专业成果。插件按需安装，让作者提出目标、Agent操作工程、作者在适合的工作面阅读和选择。

## 定义与首版

播客工坊是河图洛书JS／TS专业插件。把单集结构、主持串词、实际录音取舍和章节标记保存在同一可接续工程中。用户包括独立作者、编辑与外部Agent。默认旅程：固定节目目标和台本 → 接入真实录音与准确选段 → 章节和独立出场 → 核对实际时长 → 试听并按固定意见返工 → 复核旧编排 → WAV、章节JSON和完整工程。

首版包含完整专业维护、准确来源回读、并行方案、局部备选、意见、改稿影响、上下文、固定交接、JSON／Markdown／HTML工程及专业阅读本。功能必须经机器入口执行，作者可以自然语言提出目标，也保留人工优化入口。

## 边界

有声剧拥有多角色混音，朗读审阅拥有文本听读，字幕工坊拥有字幕对齐。本包维护节目结构、顺序剪接、实际声音与章节。外部工具负责录音、识别、复杂混音及生成，不包含RSS托管、发布、投放和付费服务。正文、正式设定、素材、采纳与定稿由宿主和作者掌握，不另建数据库、模型渠道或内部Agent。

成功以真实创作、审阅、返工及下一轮接续为准，安装、动作数或文件存在都不足以代表完成。开发与验收状态只由08维护。
